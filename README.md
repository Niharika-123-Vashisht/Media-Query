# Blog Card Project

A simple responsive Blog Card built using HTML and CSS.

## Features

- Responsive design using Media Query
- Clean card layout
- Featured image
- Author section
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3

## Project Structure

```text
project-folder/
│
├── index.html
├── style.css
└── README.md
```

## Preview

The card contains:

- Blog image
- Category label
- Publish date
- Blog title
- Description
- Author information

## How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
